# Miniaturas y dados oficiales provisionales

Copias idénticas de los PNG entregados en `NUKE3000_animaciones_prototipo.zip`, extraídos de la página MATERIAL (p.5) del Reglamento V4 aportado por el propietario. Integración autorizada dentro de NUKE3000 por `PROMPT_PARA_R2.md`. No son modelos 3D ni imágenes generadas; no se usan miniaturas de terceros.

`board_reference.png`, el HTML de demo y `demo.js` no forman parte del runtime. El fondo y los 60 hexágonos originales siguen siendo los del juego.

Para sustituir esta versión provisional: fotografías frontal, tres cuartos y lateral de soldado, meca, aeronave, escorpión, misil y base nuclear, con fondo neutro, luz uniforme, figura completa y al menos 2000 px de alto. Para colores de facción auténticos, una serie por facción. También convienen fotos nítidas de D6/D12/D20. No se ampliarán inventando detalles ni sustituyendo los recortes por SVG genéricos.
